Aplicativo local de preparação para concursos, com SQLite, PDFs e OCR offline, análise de editais com conferência humana, ciclo, Pomodoro, questões, revisões, hábitos e backup.

Para usar no Windows 10/11 x64:

- **Cronograma-de-Estudos-Windows-x64.exe**: versão portátil; baixe e abra com dois cliques.
- **cronograma-windows.zip**: alternativa compactada da versão portátil; extraia antes de abrir.
- **SHA256SUMS.txt**: hashes para conferir a integridade dos downloads.

Esta entrega contém a versão portátil. O instalador NSIS é uma etapa separada e não está anexado.

Não é necessário instalar Node.js para usar o aplicativo. Os dados ficam no perfil local do usuário. Não há dados demonstrativos incluídos.

A análise de editais usa regras e precisa de conferência humana. A aplicação não é assinada digitalmente. Os testes automatizados não substituem a validação manual de instalação e uso no seu computador. Consulte o README e docs/ENTREGA.md no código-fonte para todas as funcionalidades e limitações.
